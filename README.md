# ZOO online

## Opis projektu

ZOO online to prosty projekt strony internetowej prezentującej wybrane zwierzęta.

W ramach mojego zadania do strony została dodana sekcja poświęcona lwu. Sekcja zawiera nazwę zwierzęcia, zdjęcie oraz krótki opis.

## Wykorzystane technologie

- HTML5
- Git
- GitHub
- Trello
- Visual Studio Code

## Struktura projektu

- `index.html` – główny plik strony internetowej
- `img/` – katalog zawierający zdjęcia zwierząt
- `README.md` – opis projektu
