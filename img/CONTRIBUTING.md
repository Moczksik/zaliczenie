# Zasady współpracy

## Wprowadzenie

Dokument opisuje zasady współpracy dla osób, które chciałyby rozwijać projekt ZOO online.

## Tworzenie gałęzi

Każda zmiana powinna być wykonywana na osobnej gałęzi.

Przykład nazwy gałęzi:

```text
zwierze-imie
```

## Commity

Każdy commit powinien:

- dotyczyć jednego logicznego zestawu zmian,
- posiadać krótki i czytelny opis,
- informować, co zostało dodane lub zmienione.

## Pull request

Po zakończeniu pracy należy:

1. wysłać swoją gałąź do GitHuba,
2. utworzyć pull request,
3. opisać wykonane zmiany.

## Komunikacja

W sprawach dotyczących projektu należy komunikować się przez GitHub oraz Trello.
